
# DevBoard — Task Manager

A responsive task management dashboard built with HTML, CSS, and JavaScript.

## Features

- Add and delete tasks
- Mark tasks as completed
- Search tasks by title
- Filter tasks by status
- Track total, active, and completed tasks
- View task completion progress
- Save tasks using browser localStorage
- Responsive layout for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a browser.
3. Add tasks and manage your daily workflow.

## What I Learned

- DOM manipulation and event handling
- Working with arrays and objects
- Filtering and updating task data
- Persisting data with localStorage
- Building a responsive user interface
